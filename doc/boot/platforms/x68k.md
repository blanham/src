# NetBSD/x68k Boot Documentation

## Platform Overview

NetBSD/x68k supports the Sharp X68000 series, Japanese personal computers that were popular in the late 1980s and early 1990s. Known for excellent graphics and sound capabilities, the X68000 was a favorite for gaming and multimedia applications in Japan.

**Supported Models:**
- X68000 (Original) - 68000 @ 10 MHz (NOT SUPPORTED - no MMU)
- X68000 ACE - 68000 @ 10 MHz (NOT SUPPORTED - no MMU)
- X68000 EXPERT - 68000 @ 10 MHz (NOT SUPPORTED - no MMU)
- X68000 PRO - 68000 @ 10 MHz (NOT SUPPORTED - no MMU)
- X68000 SUPER - 68000 @ 10 MHz (NOT SUPPORTED - no MMU)
- X68000 XVI - 68000 @ 16 MHz with 68851 (SUPPORTED if PMMU installed)
- X68030 - 68030 @ 25 MHz (SUPPORTED)

**Note:** Only models with MMU are supported (68030 or 68000 with 68851 PMMU add-on).

**Key Features:**
- Human68k operating system (native OS)
- High-resolution graphics (512x512, 768x512)
- 65536 colors
- FM synthesis sound (YM2151)
- ADPCM sound
- MIDI interface
- SCSI interface (internal or external)
- Floppy drives (2HD/2DD)
- Expansion slots

## Boot Method

X68000 systems boot from Human68k (the native operating system), similar to how Amiga boots from AmigaOS. NetBSD uses a Human68k application as the bootloader.

### Boot Chain

1. **X68000 ROM** - System ROM with IPL (Initial Program Loader)
2. **Human68k** - Native operating system (version 3.x recommended)
3. **NetBSD Bootloader** - Human68k .x executable
4. **NetBSD Kernel** - `/netbsd`

### Human68k

**Operating System:**
- Human68k 2.x or 3.x required
- Version 3.02 recommended
- MS-DOS-like command line interface
- File system similar to FAT

**Boot Process:**
1. X68000 ROM loads Human68k from disk
2. User runs NetBSD bootloader from Human68k
3. Bootloader loads kernel
4. Kernel takes over system

## Boot Loaders

### boot (Primary Method)

**Location:** `/sys/arch/x68k/stand/boot/`

**Type:** Human68k .x executable

**Features:**
- Runs from Human68k command line
- Interactive boot prompt
- FFS filesystem support
- SCSI and floppy disk support
- Network boot support (via NE2000-compatible cards)
- Boot flag configuration

**Usage:**
```
A:\> boot [device:][kernel] [-flags]
```

**Examples:**
```
A:\> boot sd0a:netbsd              # Boot from SCSI disk 0, partition a
A:\> boot fd0a:netbsd -s           # Boot from floppy, single-user
A:\> boot nfs:netbsd               # Network boot
A:\> boot -a                       # Ask for root device
```

**Boot Devices:**
- `sd<ID><PART>` - SCSI disk (ID 0-7, PART a-p)
- `cd<ID>a` - SCSI CD-ROM
- `fd<UNIT>a` - Floppy disk (unit 0-3)
- `nfs` - NFS network boot

### loadbsd (Alternate)

**Simpler loader** for basic booting, fewer features than boot.

## 68030 MMU Setup

### X68030 (68030 @ 25 MHz)

**Primary supported configuration:**
- MC68030 with integrated MMU
- MC68882 FPU coprocessor
- Standard 68030 MMU setup

**MMU Initialization:**
```assembly
| 68030 MMU setup
pmove   %a0@,%crp       | Load CPU root pointer
pmove   %a1@,%tc        | Load translation control
pflusha                 | Flush TLB
pmove   %a2@,%tt0       | Transparent translation
```

**Memory Management:**
- Three-level page tables
- 4KB pages
- Standard 68030 virtual memory

### X68000 XVI with 68851 (Optional)

**If 68851 PMMU installed:**
- External MC68851 PMMU
- Compatible with 68030 MMU
- Same pmove instructions
- Two-level page tables

**Detection:**
```c
// Check for PMMU presence
if (has_68851_pmmu())
    mmutype = MMU_68851;
else
    panic("MMU required for NetBSD");
```

## Boot Process Stages

### Stage 1: Human68k Environment

**Prerequisites:**
- Human68k 2.x or 3.x installed
- Boot loader (.x file) on accessible disk
- NetBSD kernel on accessible filesystem

**Launching Bootloader:**
```
A:\> cd \netbsd
A:\NETBSD> boot
```

**Environment:**
- Running in Human68k
- Using Human68k I/O system
- Memory managed by Human68k
- Devices accessed via Human68k drivers

### Stage 2: Bootloader Execution

**Location:** `/sys/arch/x68k/stand/boot/boot.c`

**Process:**
1. Parse command line arguments
2. Detect hardware configuration:
   - CPU type (68030 required)
   - FPU presence
   - Memory size
   - SCSI host adapter type
3. Initialize device drivers
4. Load kernel from specified device
5. Prepare boot information
6. Disable Human68k
7. Jump to kernel

**Hardware Detection:**
```c
// Detect SCSI host adapter
int get_scsi_host_adapter(void) {
    uint32_t bootinf = IOCS_BOOTINF();

    if (bootinf < 0xa0)
        return 0; // Booted from FD

    // Check boot ROM signature
    char *bootrom = (char *)(bootinf & 0x00ffffe0);
    if (*(u_short *)(bootrom + 0x24 + 4) == 0x494e)
        ha = (X68K_BOOT_SCSIIF_SPC << 4) | 0; // Internal SCSI
    else if (badbaddr(EXSCSI_BDID))
        ha = (X68K_BOOT_SCSIIF_MHA << 4) | 0; // Mankai SCSI
    else
        ha = (X68K_BOOT_SCSIIF_SPC << 4) | 1; // External SCSI

    return ha;
}
```

**Device Parsing:**
```c
// Parse device specification: ha@dev:path
// Examples:
//   sd0a:netbsd       - SCSI ID 0, partition a
//   spc0@sd1b:kernel  - Specific host adapter
//   fd0a:netbsd       - Floppy drive 0
```

### Stage 3: Kernel Entry

**Location:** `/sys/arch/x68k/x68k/locore.s`

**Entry Point:** `start`

**Initial State:**
- Running in physical memory
- Human68k may have enabled MMU (must reset)
- Interrupts should be disabled
- Boot parameters in registers

**Entry Code:**
```assembly
    .text
GLOBAL(kernel_text)

ASENTRY_NOPROFILE(start)
    movw    #PSL_HIGHIPL,%sr    | Disable interrupts

    | Save boot parameters
    | Boot information passed in registers and/or structure

    | Detect CPU type
    movl    #CACHE_OFF,%d0
    movc    %d0,%cacr           | Disable caches

    | Clear any previous MMU state (from Human68k)
    | Initialize our own MMU tables

    | Detect hardware configuration
    | - Memory size
    | - Video mode
    | - SCSI configuration
    | - Network interface

    | Setup temporary stack
    lea     _ASM_LABEL(tmpstk),%sp

    | Initialize 68030 MMU
    | Setup page tables
    | Enable MMU and caches

    | Jump to C code
    jbsr    _C_LABEL(main)
```

### Stage 4: Machine Initialization

**Location:** `/sys/arch/x68k/x68k/machdep.c`

**Initialization:**
1. Complete MMU setup
2. Initialize memory management
3. Configure X68000-specific devices:
   - Graphics (CRTC, video controller)
   - Sound (OPM, ADPCM)
   - SCSI (SPC or MHA)
   - Serial (SCC Z8530)
   - Keyboard
   - Mouse
   - Joystick
4. Setup interrupt system (MFP 68901)
5. Initialize RTC (RP5C15)
6. Mount root filesystem
7. Start init

**X68000-Specific Setup:**
```c
// Detect X68000 model
void identify_x68k(void) {
    // Read system configuration from SRAM
    // Determine model, memory, peripherals
}

// Initialize video subsystem
void video_init(void) {
    // Setup CRTC for console
    // Initialize text/graphics layers
    // Configure palette
}
```

## Memory Map

```

0x00000000 - 0x00BFFFFF    Main RAM (typically 1-12MB)
  0x00000000 - 0x00001FFF    Exception vectors
  0x00002000 - 0x00001FFF    Human68k system area (preserve)
  0x00080000 - ...           Available RAM
  ...                        Kernel load area

0x00C00000 - 0x00DFFFFF    Graphics VRAM
  0x00C00000 - 0x00C7FFFF    Text VRAM (512KB)
  0x00C80000 - 0x00CFFFFF    Graphics VRAM page 0 (512KB)
  0x00D00000 - 0x00D7FFFF    Graphics VRAM page 1 (512KB)
  0x00D80000 - 0x00DFFFFF    Graphics VRAM page 2 (512KB)

0x00E00000 - 0x00E7FFFF    SRAM and System Area
  0x00E80000               User SRAM (16KB)
  0x00E86000               System port
  0x00E8E000               RTC (RP5C15)
  0x00E90000               Printer port
  0x00E92000               SYSPORT
  0x00E94000               FM sound (OPM YM2151)
  0x00E96000               ADPCM
  0x00E98000               FDC (Floppy)
  0x00E9A000               FDD control
  0x00E9C000               HD controller
  0x00EA0000               SCSI (internal SPC)
  0x00EAC000               SCC (Z8530 serial)
  0x00EB0000               PPI (keyboard/mouse)
  0x00ECC000               RTC/SRAM control

0x00EB0000 - 0x00EBFFFF    PPI and controls
0x00EC0000 - 0x00ECFFFF    Sprites and BG

0x00ED0000 - 0x00EFFFFF    System ROM area

0x00F00000 - 0x00FBFFFF    User I/O area (expansion)

0x00FC0000 - 0x00FDFFFF    Reserved

0x00FE0000 - 0x00FFFFFF    CGROM (Character Generator ROM)

0x01000000 - ...           Extended RAM (if installed)

Virtual Address Layout:
0x00000000 - 0x000007FF    Unmapped (NULL trap)
0x00000800 - ...           Kernel text/data
...                        Kernel heap
0x01000000 - ...           User space
0x00C00000 - 0x00FFFFFF    Direct-mapped I/O
```

## Build and Installation

### Building Bootloader

```bash
cd /usr/src/sys/arch/x68k/stand
make depend && make
```

**Products:**
- `boot` - Main bootloader (.x executable)
- `loadbsd` - Alternate simple loader

**Installation to Human68k disk:**
```bash
# Copy to Human68k-accessible media
cp boot /mnt/human68k/boot.x
```

### Building Kernel

```bash
cd /usr/src/sys/arch/x68k/conf
config GENERIC
cd ../compile/GENERIC
make depend && make
```

**Kernel Configuration:**
- `GENERIC` - Standard configuration
- `INSTALL` - Installation kernel with memory disk

### Installation

**Prepare Human68k Boot Disk:**
1. Format floppy or hard disk with Human68k
2. Install Human68k 3.x
3. Copy NetBSD bootloader
4. Copy NetBSD kernel

**Create NetBSD Partition:**
```bash
# From NetBSD or cross-tools
# Create BSD disklabel on SCSI disk
# Format with newfs
# Install distribution
```

**Boot Setup:**
```
A:\> copy netbsd C:\
A:\> copy boot.x C:\
A:\> C:
C:\> boot netbsd
```

## Debugging

### Serial Console

**Hardware:**
- RS-232C port (25-pin D-sub)
- Standard serial connection

**Configuration:** 9600 8N1 (typical)

**Enable:**
```c
// In kernel config
options SERCONSOLE
```

**Or at boot:**
```
A:\> boot netbsd -h  # Serial console flag
```

### DDB (Kernel Debugger)

**Enable:**
```
options DDB
options DDB_HISTORY_SIZE=512
```

**Break:**
- Press BREAK key
- Serial BREAK
- Programmed breakpoint
- Panic

### Common Boot Issues

**"CPU not supported"**
- **Cause:** 68000 without MMU
- **Solution:** Need 68030 or 68000+68851

**"Cannot load kernel"**
- **Cause:** File not found or wrong device
- **Solution:**
  - Verify path
  - Check device syntax (sd0a:, fd0a:, etc.)
  - Ensure filesystem readable

**"Not enough memory"**
- **Cause:** Insufficient RAM for kernel
- **Solution:**
  - Need at least 4MB
  - Remove Human68k TSRs
  - Use smaller kernel

**Graphics corruption**
- **Cause:** Video mode mismatch
- **Solution:**
  - Try serial console
  - Check CRTC settings
  - Use standard video mode

**SCSI timeout**
- **Cause:** SCSI configuration or termination
- **Solution:**
  - Check SCSI IDs
  - Verify termination
  - Check cable

## Hardware Support

**Working:**
- CPU: 68030 @ 25 MHz
- FPU: 68882 coprocessor
- RAM: 1-12MB (more with expansion)
- Graphics: Text and graphics layers
- SCSI: Internal SPC (MB89352)
- SCSI: External adapters
- Serial: SCC Z8530 (2 ports)
- Floppy: 2HD/2DD drives
- Keyboard: X68000 keyboard
- Mouse: X68000 mouse
- RTC: RP5C15

**Partial:**
- Sound: OPM/ADPCM (basic support)
- Network: NE2000-compatible ISA cards
- Joystick: Basic support

**Not Supported:**
- MIDI interface
- Sprite/BG hardware acceleration
- Some graphics modes
- Some expansion cards

## Historical and Cultural Note

The Sharp X68000 holds a special place in Japanese computing history:
- Launched 1987, discontinued 1993
- Known as "X68k" (エックスろくはちケー)
- Excellent graphics and sound for era
- Popular for arcade game ports
- Active demo scene and homebrew
- Collectible and expensive today
- NetBSD provides modern Unix environment

**Name Origin:**
- "X68000" indicates 68000 CPU family
- Competing with Amiga and Mac
