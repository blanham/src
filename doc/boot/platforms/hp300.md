# NetBSD/hp300 Boot Documentation

## Platform Overview

NetBSD/hp300 supports HP 9000 Series 300 and 400 workstations, which were HP's 68k-based Unix workstations from the late 1980s and early 1990s.

**Supported Models:**
- HP 9000/300 series (310, 320, 330, 340, 350, 360, 370, 375, 380, 385)
- HP 9000/400 series (400s, 400t, 425s, 425t, 433s, 433t)

**CPUs:**
- 68010 @ 10 MHz (310)
- 68020 @ 16.67 MHz (320, 330, 350)
- 68030 @ 25/33/50 MHz (340, 360, 370, 375, 380, 385, 425, 433)
- 68040 @ 25/33 MHz (380, 385, 425, 433)

**Note:** 68010 support requires special consideration due to lack of PMMU.

## Boot Method

HP 9000 systems boot from the ROM monitor, which provides bootstrap code to load the NetBSD bootloader from disk or LAN.

### Boot Chain

1. **ROM Monitor** - HP's firmware (pre-boot environment)
2. **LIF Bootloader** - `uboot.lif` - Primary bootloader
3. **Secondary Boot** - `/boot` - Loads kernel
4. **NetBSD Kernel** - `/netbsd`

### Logical Interchange Format (LIF)

HP systems use LIF (Logical Interchange Format) instead of traditional boot sectors.

**LIF Structure:**
- Volume header with directory
- Boot program in first 256KB
- Standard filesystem after boot area

## Boot Methods

### 1. Disk Boot

**Preparation:**
```bash
# Install bootloader to disk
cd /usr/mdec
installboot /dev/rsd0a uboot.lif bootxx
```

**Boot Process:**
1. ROM monitor loads LIF bootloader
2. Bootloader locates `/boot` on FFS filesystem
3. `/boot` loads `/netbsd` kernel
4. Kernel takes over

**At ROM prompt:**
```
> boot sd0
or
> boot hd(0,0,0):
```

### 2. Network Boot

**Server Setup:**
```bash
# Configure RARP
echo "08:00:09:xx:xx:xx hostname" >> /etc/ethers
echo "192.168.1.100 hostname" >> /etc/hosts

# Configure BOOTP/DHCP
# /etc/dhcpd.conf entry

# Configure TFTP
cp /usr/mdec/uboot.lif /tftpboot/boot.hp300
```

**Boot from ROM:**
```
> boot lan
```

### 3. Tape Boot

For installation:
```
> boot ct
```

Loads miniroot from tape device.

## 68020/68030/68040 MMU Differences

### 68020 with 68851 External PMMU

**Characteristics:**
- External 68851 chip required
- Full page-based virtual memory
- Root/Supervisor pointer registers (CRP/SRP)
- Translation Control (TC)
- Function codes (FC0-FC7)

**Setup:**
```assembly
pmove   %a0@,%crp       | Load CPU root pointer
pmove   %a1@,%tc        | Load translation control
pflusha                 | Flush TLB
```

### 68030 Integrated MMU

**Similar to 68851 but integrated:**
- Compatible with 68851 instructions
- Faster execution
- Transparent translation (TT0/TT1)

### 68040 Integrated MMU

**Different architecture:**
- Four-level page tables
- URP/SRP instead of CRP
- TTR registers instead of TT
- Different opcode encoding

**Setup:**
```assembly
.long   0x4e7b1807      | movc d1,srp
.word   0xf518          | pflusha
movl    #MMU40_TCR,%d0
.long   0x4e7b0003      | movc d0,tc
```

## Boot Process Stages

### Stage 1: ROM Monitor

**Functions:**
- Hardware initialization
- Device probing
- Boot device selection
- Load LIF bootloader

**ROM Commands:**
- `boot` - Boot from device
- `search` - Search for bootable devices
- `ird` - Integrated ROM Debugger
- `set bootdev` - Set default boot device

### Stage 2: LIF Bootloader (uboot.lif)

**Location:** `/sys/arch/hp300/stand/uboot/`

**Size:** Max 256KB (LIF limitation)

**Functions:**
- Minimal filesystem support
- Load `/boot` from FFS
- Pass control to secondary boot

### Stage 3: Secondary Boot (/boot)

**Location:** `/sys/arch/hp300/stand/common/boot.c`

**Functions:**
- Full FFS support
- Interactive boot prompt
- Kernel loading
- Boot parameter passing

**Boot Prompt:**
```
Boot: [[[device:]kernel] [-opts]]
```

**Examples:**
```
Boot: netbsd              # Boot default kernel
Boot: netbsd -s           # Single user
Boot: netbsd.old          # Alternate kernel
Boot: sd(0,0,0):netbsd    # Specify device explicitly
```

### Stage 4: Kernel Entry

**Location:** `/sys/arch/hp300/hp300/locore.s`

**Entry Point:** `start`

**Initial Actions:**
1. Save boot parameters
2. Detect CPU type
3. Initialize MMU
4. Setup page tables
5. Enable caches
6. Jump to C code (`main()`)

## Memory Map

### Physical Address Space

```
0x00000000 - 0x00FFFFFF    Main RAM (up to 16MB on older models)
                            (up to 256MB on newer 68040 models)

0x41000000 - 0x42000000    DIO/DIO-II I/O space (16MB)
                            Device-Independent I/O bus

0xFFxxxxxx                 Internal I/O and ROM
  0xFFF00000 - 0xFFFFFFFF    ROM monitor
```

### DIO Bus Devices

Each DIO slot occupies 64KB in the DIO address space:
- Graphics framebuffers
- Network interfaces (LAN9000)
- HPIB (HP-IB/IEEE-488) interfaces
- Serial ports
- SCSI controllers

### Kernel Virtual Address Space

```
0x00000000 - 0x000007FF    Unmapped (NULL trap)
0x00000800 - ...           Kernel text/data
...                        Kernel heap
...                        Page tables
0x80000000 - ...           User space (varies by model)
```

## Build and Installation

### Building Bootloader

```bash
cd /usr/src/sys/arch/hp300/stand
make depend
make
make install DESTDIR=/targetroot
```

**Products:**
- `uboot.lif` - LIF bootloader
- `boot` - Secondary bootloader
- `installboot` - Installation tool

### Building Kernel

```bash
cd /usr/src/sys/arch/hp300/conf
config GENERIC
cd ../compile/GENERIC
make depend
make
```

### Installation

**Install bootloader:**
```bash
cd /usr/mdec
installboot /dev/rsd0a uboot.lif bootxx
```

**Install kernel:**
```bash
cp netbsd /targetroot/netbsd
```

**Install secondary boot:**
```bash
cp /usr/mdec/boot /targetroot/boot
```

## Debugging

### ROM Debugger

**Enter debugger:**
```
> ird
```

**Useful commands:**
- `d <addr>` - Display memory
- `m <addr>` - Modify memory
- `g <addr>` - Go to address
- `b <addr>` - Set breakpoint
- `r` - Display registers

### Serial Console

Most HP 300/400 systems have 3 serial ports:
- Port 0: Console (9600 8N1)
- Port 1: Remote
- Port 2: Printer

**Enable serial console:**
```
> set console remote
```

### DDB Debugging

**Build kernel with DDB:**
```
options DDB
```

**Break into debugger:**
- Press Ctrl-Alt-Esc on console
- Or trigger panic

## Common Issues

### "No LIF bootloader"
- **Solution:** Reinstall with `installboot`

### "Cannot load /boot"
- **Cause:** Filesystem corruption or wrong LIF format
- **Solution:** Reinstall bootloader and `/boot`

### "Unknown CPU type"
- **Cause:** Unsupported model
- **Solution:** Check supported models list

### System hangs at boot
- **Cause:** Bad RAM, incompatible peripherals
- **Solution:** Remove DIO cards, test RAM
